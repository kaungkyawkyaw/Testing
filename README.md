# Portfolio Web Application (testing)

Personal Portfolio / Company Agency Landing Page တစ်ခုဖြစ်ပြီး HTML5, Pure CSS နှင့် JavaScriptဖြင့် ရေးသားတည်ဆောက်ထားခြင်းဖြစ်သည်။

---

## 📌 Project Overview (ပရောဂျက် အကျဉ်းချုပ်)

* **Language:** HTML5, CSS3, JavaScript (Vanilla JS)
* **Design Type:** Responsive Landing Page
* **Primary Target:** Web Showcase for Portfolio, Services, Skills, and Tech Events.

---

## ✨ Features (ပါဝင်သော အစိတ်အပိုင်းများနှင့် လုပ်ဆောင်ချက်များ)

1. **Header & Navigation (ခေါင်းစဉ်နှင့် လမ်းညွှန်):**
   * **Top Contact Bar:** ဖုန်းနံပါတ် ၊ အီးမေးလ် နှင့် Social Media Link များ (Facebook, Telegram, Viber) ပါဝင်သည်။
   * **Responsive Navigation Bar:** Mobile screen များအတွက် Hamburger Menu Toggle ပါဝင်ပြီး၊ Dropdown Menu (My Projects) ပါဝင်သည်။

2. **Hero Section:**
   * Headline: *"Architecting Scalable Web Systems & Clean Code"*
   * Senior Full-Stack Engineer အတွက် Introduce ဖြင့် ဆွဲဆောင်မှုရှိသော CTA (Call to Action) Button ပါဝင်သည်။

3. **About Us Section:**
   * ကုမ္ပဏီ သို့မဟုတ် မိမိ၏ မစ်ရှင်၊ ဗီဇင် နှင့် လုပ်ငန်းအတွေ့အကြုံဆိုင်ရာ Stats Grid ပါဝင်သည်။
   * Our Vision & Mission

4. **Projects Showcase:**
   * Card Slider ပုံစံဖြင့် E-commerce App, Hotel Booking App, Car Website, WordPress Projects များကို Interactive Overlay နှင့် Arrow Buttons များဖြင့် ဖော်ပြထားသည်။

5. **Skills Section:**
   * CSS Radio Button Hack ကို အသုံးပြု၍ Tab Switch / Interactive View ပြုလုပ်ထားသော Tech Stack Showcase (WordPress, PHP, Python, JavaScript) ပါဝင်သည်။

6. **Events & Activities Section:**
   * MICT Park Meetups, BarCamp Yangon, Local Startup Launches အစရှိသော သတင်းများနှင့် ပွဲအခမ်းအနားများကို Card Grid Layout ဖြင့် ပြသထားသည်။

7. **Footer Section:**
   * ဆက်သွယ်ရန် လိပ်စာ၊ ဖုန်း၊ အီးမေးလ်၊ Language Fluencyနှင့် Social Links များ ပါဝင်သည်။

## 🛠️ Built With (အသုံးပြုထားသော နည်းပညာများ)

* **HTML5:** Semantic HTML Tags များ (header, main, section, footer) အသုံးပြုထားသည်။
* **Font Awesome (v6.4.0):** Social Icons, Menu Icons နှင့် Arrows များအတွက် အသုံးပြုထားသည်။
* **Lucide Icons:** Event Card များတွင် Calendar နှင့် Arrow Icons များအတွက် အသုံးပြုထားသည်။
* **Devicon CDN:** Tech Stack Icons (WordPress, PHP, Python, JS) များအတွက် အသုံးပြုထားသည်။
* **Vanilla JavaScript:** Mobile Navigation Bar Toggle ပြုလုပ်ရန်နှင့် Lucide Icons Render လုပ်ရန် အသုံးပြုထားသည်။
